# dotfiles

Personal macOS dotfiles, managed with [chezmoi](https://chezmoi.io).

Source dir: `~/src/github.com/drasewkit/dotfiles` (set via `~/.config/chezmoi/chezmoi.toml`).

> Bootstrap instructions and a one-line install come in a later phase (P5).
> No secrets live in this repo — SSH/GPG keys are regenerated per machine (D5).
